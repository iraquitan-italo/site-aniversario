# site-web-aniversario

Site romântico interativo desenvolvido como uma surpresa de aniversário.

Este projeto foi criado utilizando **HTML, CSS e JavaScript**, com o objetivo de praticar conceitos de **desenvolvimento front-end e manipulação do DOM**, além de criar uma experiência visual interativa.

Funcionalidades do projeto:

• Galeria de fotos com navegação por setas
• Visualização ampliada das imagens ao clicar
• Animação de corações caindo na tela
• Contador de tempo do relacionamento
• Campo de senha para desbloquear uma surpresa
• Mensagem romântica com efeito de digitação
• Música de fundo

O projeto também serviu como prática para **interatividade, design de interface e manipulação de eventos em JavaScript**.
